Configuration

This console can start and stop the commands declared in your mabo-ctl.yaml. It is bound to a loopback address and every mutation carries a per-session token that only this page has been shown. Treat the URL mabo-ctl printed as a credential.

Environment values are redacted server-side by key and by shape; only the variables declared in mabo-ctl.yaml are listed here, never the environment mabo-ctl inherited.
